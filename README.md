# Dove lo guardo?

Progetto pronto per Vercel.

## Come pubblicarlo
1. Crea un repository GitHub e carica questi file.
2. Su Vercel importa il repository e fai Deploy.
3. In Vercel vai su Settings > Environment Variables.
4. Crea `STREAMING_API_KEY` e incolla come valore la tua API key di Streaming Availability API.
5. Salva e fai Redeploy.

Non inserire la chiave API nei file del progetto.
